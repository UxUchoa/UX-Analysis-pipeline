# UX Analysis Pipeline

A local app that analyzes UX research from spreadsheets. It combines a React frontend, a FastAPI backend and a local LLM through Ollama to process usability tests and profile mapping interviews **without sending any data to external services**.

[🇧🇷 Leia em português](#-português)

## Features

Upload `.xlsx`, `.xls` or `.csv` files; a new table can be uploaded at any time, even with one already loaded. The backend automatically detects the kind of dataset:

- **Usability test:** spreadsheets with tasks, missions, per-participant observations and time marks.
- **Profile mapping:** context interviews with demographics, open questions and scale ratings.
- **Generic/quantitative:** tabular data that doesn't follow the expected UX scripts.

**Usability tests:** success, difficulty and non-completion rates; difficulty index per task; durations extracted from marks such as `Min Início` and `Min Fim`; per-task detail with participant, status, duration and cleaned observation; distributions for overall status, sample profile, age range and the participants with the most friction.

**Profile mapping:** sample profile by age, sex/gender, management/team and experience; distribution by team; satisfaction/confidence scores on a 1–5 scale; ranking of recurring themes in open answers; filtering of rows that aren't completed interviews.

**Local AI analysis:** executive summary, insights, evidence, severity, anomalies and recommendations generated by Ollama with `qwen3:4b`, with normalization and a fallback for invalid LLM output. All data is processed locally.

## Getting started

Requirements: Python 3.9+, Node.js 18+ and Ollama running locally with the `qwen3:4b` model.

**First-time setup:**

```bash
cd UX-Analysis-pipeline
python -m venv .venv
.venv\Scripts\activate
pip install -r backend/requirements.txt
cd frontend && npm install && cd ..
ollama pull qwen3:4b
```

**Run it** (three terminals open at the same time):

```bash
ollama serve                                                   # terminal 1
.venv\Scripts\activate
python -m uvicorn backend.main:app --reload --port 8000        # terminal 2
cd frontend && npm run dev                                     # terminal 3
```

Open `http://localhost:5173`. The API runs at `http://localhost:8000` (quick check: `/api/health`). If Ollama says the port is already in use, it's probably already running.

## How to use it

1. Upload a `.xlsx`, `.xls` or `.csv` spreadsheet.
2. Check the overview and the automatically detected dataset type.
3. Browse the specific panels in the **Visualizations** tab.
4. Optionally give the analysis some context.
5. Click **Analyze with AI** to generate insights through Ollama.
6. Export the data or the report when needed.

## Main API

| Endpoint | Purpose |
| --- | --- |
| `GET /api/health` | Checks the backend and the Ollama connection. |
| `POST /api/upload` | Receives the spreadsheet, cleans it and detects its type. |
| `GET /api/visualizations` | Returns data ready for the panels. |
| `POST /api/analyze` | Runs the local AI analysis. |
| `GET /api/export/csv` / `excel` | Exports the loaded dataset. |
| `GET /api/export/report` | Exports the AI report as JSON. |

## Project structure

```text
backend/main.py              FastAPI API
backend/data_processing.py   cleaning, classification and visualization data
frontend/src/                React app: layout, HTTP client, PT/EN translations, panels and tables
samples/                     usability test and profile mapping examples
ux_excel_analyzer.py         analysis engine with Ollama
```

The `samples/` folder has `Teste_Usabilidade_*.xlsx` and `Mapeamento_Perfil_*.xlsx` examples to validate task, time, status, profile, score and theme extraction.

## Troubleshooting

- **`ollama` not recognized:** install Ollama and open a new terminal.
- **Model not found:** `ollama pull qwen3:4b`.
- **`python` or `npm` not recognized:** install Python 3.9+ (add to PATH) or Node.js 18+ and open a new terminal.
- **Frontend opens but shows no data:** make sure the backend is running on port `8000`.

# UX Analysis Pipeline

Aplicação local para análise de pesquisas UX a partir de planilhas. O app combina um frontend em React, um backend em FastAPI e análise com LLM local via Ollama para processar testes de usabilidade e mapeamentos de perfil sem enviar dados para serviços externos.

## Funcionalidades

O upload aceita arquivos `.xlsx`, `.xls` e `.csv`. Uma nova tabela pode ser enviada a qualquer momento, mesmo quando já existe um arquivo carregado.

O backend detecta automaticamente o tipo de base:

- **Teste de usabilidade**: planilhas com tarefas, missões, observações por participante e marcações de tempo.
- **Mapeamento de perfil**: entrevistas de contexto com dados demográficos, perguntas abertas e notas em escala.
- **Genérico/quantitativo**: bases tabulares que não seguem os roteiros UX esperados.

### Testes de Usabilidade

- Taxa de sucesso, dificuldade e não realização.
- Índice de dificuldade por tarefa.
- Extração de tempo a partir de marcações como `Min Início` e `Min Fim`.
- Detalhamento por tarefa com participante, status, duração e observação limpa.
- Distribuições úteis para o cenário: status geral, perfil da amostra, faixa etária e participantes com mais fricção.

### Mapeamento de Perfil

- Perfil da amostra por idade, sexo/gênero, gerência/equipe e tempo de experiência.
- Distribuição por gerência/equipe.
- Notas de satisfação/confiança em escala de 1 a 5.
- Ranking de temas recorrentes em respostas abertas.
- Filtragem de linhas que não representam entrevistas realizadas.

### Análise com IA Local

- Geração de resumo executivo, insights, evidências, severidade, anomalias e recomendações.
- Uso do Ollama local com o modelo `qwen3:4b`.
- Normalização e fallback para respostas inválidas do LLM.
- Dados processados localmente.

## Instalação

Faça estes passos apenas na primeira vez que for preparar o projeto.

1. Entre na pasta do projeto:

```bash
cd UX-Analysis-pipeline
```

2. Crie o ambiente virtual do Python:

```bash
python -m venv .venv
```

3. Ative o ambiente virtual:

```bash
.venv\Scripts\activate
```

Se o comando deu certo, o terminal deve mostrar `(.venv)` no começo da linha.

4. Instale as dependências do backend:

```bash
pip install -r backend/requirements.txt
```

5. Instale as dependências do frontend:

```bash
cd frontend
npm install
cd ..
```

6. Baixe o modelo local usado pela IA:

```bash
ollama pull qwen3:4b
```

## API Principal

- `GET /api/health`: verifica backend e conexão com Ollama.
- `POST /api/upload`: recebe planilha, limpa dados e detecta o tipo.
- `GET /api/visualizations`: retorna dados prontos para os painéis.
- `POST /api/analyze`: executa a análise com IA local.
- `GET /api/export/csv`: exporta a base carregada em CSV.
- `GET /api/export/excel`: exporta a base carregada em Excel.
- `GET /api/export/report`: exporta o relatório de IA em JSON.
